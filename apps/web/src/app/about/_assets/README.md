# About page assets

- `geist-variable.ttf`: Geist by Vercel, sourced from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/geist). SIL Open Font License in `OFL.txt`. Self-hosted through `next/font/local`, scoped to this page.
- `/public/about/switzerland.svg`: Switzerland outline derived from [Natural Earth 1:50m country geometry](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson), [public domain](https://www.naturalearthdata.com/about/terms-of-use/). Projected as `x = 240 + (longitude - 8.23) * 92`, `y = 150 - (latitude - 46.81) * 135` into a 480 × 300 viewBox.
- The pin uses the same projection at Wil's approximate town centre (47.46152 N, 9.04552 E; [GeoNames](https://www.geonames.org/2657996/wil-sg.html)). It does not represent a street address or office entrance.

The founder artwork is typographic, not a placeholder portrait. The provided names and roles are retained; bios are editorial draft copy for review.
